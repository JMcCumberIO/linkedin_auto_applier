## Original Requirements

create a linkedin easy apply auto applier that uses openai to generate everything needed to apply

## Project Name

linkedin_auto_applier

## Product Goals

- Automate the LinkedIn Easy Apply process
- Ensure generated application content is relevant and personalized
- Enhance user privacy and data security

## User Stories

- As a job seeker, I want the tool to automatically fill out applications using my LinkedIn profile data
- As a user, I want the application content to be personalized and relevant to each job
- As a user, I want to review and edit the generated application content before submission
- As a user, I want to ensure my personal data is secure and not shared without consent
- As a user, I want to track the status of my applications

## Competitive Analysis

- Jobscan: Offers resume optimization but lacks automation for applications
- Resumake: Provides resume building but no application automation
- LinkedIn Premium: Offers job insights but no auto-apply feature
- Zety: Resume builder with templates, lacks application automation
- Glassdoor: Job search platform with company reviews, no auto-apply feature

## Requirement Analysis

The tool should integrate with LinkedIn's API to automate the Easy Apply process, leveraging OpenAI to generate personalized application content. It must prioritize user data security and allow for user review and editing of applications.
